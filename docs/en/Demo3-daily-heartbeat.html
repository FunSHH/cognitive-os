Judgment isn't "remembered"
it's "activated daily"

You can't manually check 97 judgment nodes / 22 topics every day. Another engineering feature of Cognitive OS is the "automatic heartbeat" — 5 scheduled tasks run daily, keeping all judgment nodes in active state, not silently expiring.

Below: what the engine actually runs in a single day.

A DAY'S TIMELINE · DAILY HEARTBEAT

5 scheduled tasks + your 5-minute reading

08:00· weekdays
Agent auto
Domain signal scan
Scan multiple external input sources (data / news / indicators) → filter by every Active topic's "watch variables" → write to signal pool. Ready before you wake up.
→ Signal pool gains several entries · classified (S / A / B grade) + topic assignment
08:30· weekdays
Agent auto
Daily distillation
Signal pool entries auto-route to corresponding topic evidence pools + touch related judgment nodes for evidence appending + Falsifier state re-evaluation. One signal can touch multiple judgment nodes simultaneously (see fan-out diagram below).
→ Topic pools updated · Falsifier state changes · evolution-stage transitions
09:00· morning
You (5 min)
Read today's distillation report
You open the Synthesis report — structured "today's cognitive increment": which Falsifier states changed, which topics shifted evolution-stage, which new promotion candidates. 5 minutes to read, you have the complete cognitive consequences of what happened in the system today.
→ 5 minutes vs manually tracking each node (impossible)
09:05+· deep work
You (high-value time)
Deep judgment · decision signing · protocol upgrade
You only do "what only humans can do": give the first read on new things · decide confidence shifts · sign methodology protocols · review past decisions. Everything rule-based is already done by the Agent.
Weekly Mon· one-shot
System check
Weekly health check (Lint)
Scan system + business layers: architecture consistency / metadata completeness / contradictory nodes / expired judgments / orphan nodes / promotion candidate backlog / unacted Falsifier triggers. Systems silently rot — Lint is the "anti-entropy" layer.
→ Two-layer Lint report · Promotion candidate list
Weekly Mon· cross-topic
Agent auto
Structural change scan
Weekly scan of world-level structural changes (not intraday signals — but regime shifts / rule transitions / paradigm changes). Triggers Falsifier reviews on related Cognition nodes.
→ Change pool gains entries + triggers reverse-evidence backfill to topic thesis nodes
Weekly Fri· closing
Agent auto
Topic overview audit
Scan all topics' states → horizontal matrix cross-check → auto-detect contradictions / drifts / inconsistencies. The week's judgment network completes a "holistic calibration".
→ Overview matrix · Horizontal contradictions auto-flagged

Manually maintaining this network — humans give up within a month. For an Agent, it doesn't forget, doesn't get tired, doesn't skip.

WHY THIS MUST RUN DAILY

Judgment isn't "remembered" — it's "kept active"

If not running daily

Judgments "fail by being forgotten"

~6 months

Without a regular heartbeat, judgment nodes "quietly expire". The judgments / Falsifiers / protocols you wrote 6 months ago — nobody/no agent is actively checking whether they still hold.

A judgment is no longer touched by new evidence not because it's correct, but because the system has forgotten it exists. Your judgment network silently rots.

With daily heartbeat

Judgments stay activated

5 min / day

Every new signal auto-attempts to touch all related nodes. Judgments don't expire — they're either supported, falsified, or pending review. Every day's 5-minute Synthesis read gives you the full cognitive consequences.

This is "judgment compounding" — not accumulating more, but keeping every judgment alive.

The system runs daily for you
You spend just 5 minutes reading what changed
Agent does everything rule-based · You do only what humans can do
